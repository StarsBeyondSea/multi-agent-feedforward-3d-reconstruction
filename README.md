# 跨高度智能体观测下的前馈式三维重建

## 一、研究背景与意义

### 1. 应用场景与问题特征

无人机、低空飞行平台和地面机器人可以从不同高度观测同一建筑、园区或道路场景。高空观测具有覆盖范围大、能够看到屋顶和道路整体结构的优势。低空及近地观测具有成像尺度大、能够看到建筑立面、入口和地面设施细节的优势。将这些观测组合起来，可以在较少采集次数下同时获得场景的整体布局和局部几何信息，对三维测绘、建筑巡检、灾害评估、机器人导航和数字孪生具有实际价值。

跨高度观测与普通同高度多视图重建存在不同的几何困难。高度变化会同时改变相机到场景的距离、像素对应的地面采样尺度、可见区域和遮挡关系。高空图像可能主要呈现屋顶和道路，低空图像可能主要呈现立面和地面目标，两者的共同可见区域较小。建筑边缘、树木和车辆会产生非对称遮挡，弱纹理墙面又会降低局部特征的稳定性。若直接把不同高度的图像当作同分布多视图输入，容易出现错误匹配、深度断裂、点云重影和局部区域缺失。因此，本课题将高度差视为影响观测质量和融合权重的显式因素，研究高度条件下的几何对齐、跨视角对应和三维融合问题。

### 2. 相关工作的技术演进

已有工作为本课题提供了从多视图深度推断到前馈式场景几何预测的技术基础。

- **MVSNet** 将深度学习特征、可微单应性变换和三维代价体结合起来，从经过标定的多视图图像推断参考视图深度。它说明多视图特征可以在相机视锥中进行几何对齐，也提供了适用于已知相机参数条件的经典学习式基线。它对输入视图重叠度、相机几何和可靠代价体仍有较强依赖，跨高度场景中的视野差异会直接影响代价体质量。 [论文](https://arxiv.org/abs/1804.02505)
- **LoFTR** 使用粗到细的 Transformer 自注意力与交叉注意力建立稠密对应关系，避免完全依赖关键点检测器，在低纹理区域和较大视角变化下表现出较好的匹配能力。它适合用于分析跨高度图像的对应关系，但二维匹配结果还需要结合深度、相机和可见性约束才能形成稳定的三维模型。 [论文](https://arxiv.org/abs/2104.00680)
- **DUSt3R** 把图像对重建表述为点图回归，并通过全局对齐将多个图像对的点图放入共同参考系，在缺少相机内参和位姿先验时也可以直接输出场景几何。它为前馈式、弱先验三维重建提供了重要范式，也启发本课题同时研究点图、深度和共同坐标系。极端跨高度输入下的尺度一致性、遮挡区域和全局对齐误差仍需要专门分析。 [论文](https://arxiv.org/abs/2312.14132)
- **MASt3R** 在 DUSt3R 的基础上增加稠密局部特征和匹配损失，并采用快速的互惠匹配策略，在大视角变化的图像匹配任务中进一步提升鲁棒性。它说明三维表示可以反过来帮助二维对应关系建立，但稠密匹配的计算量、错误对应的置信度以及不同高度图像的尺度差异仍是工程实现中的重要问题。 [论文](https://arxiv.org/abs/2406.09756)
- **VGGT** 以一次前向推理联合预测相机参数、点图、深度图和三维点轨迹，支持从单张、少量到大量视图的输入，论文摘要报告其重建图像耗时低于一秒。它与本课题的前馈式目标高度一致。不过，这些工作以图像集合为主要输入，尚未把智能体高度、相对高度差和观测职责作为专门条件输入。高空整体观测与低空细节观测如何分工融合，仍需要在明确的跨高度评测协议下检验。 [论文](https://arxiv.org/abs/2503.11651)

### 3. 研究空缺与课题意义

所选工作分别推进了多视图代价体构建、困难视角匹配、点图全局对齐和前馈式几何预测，但其核心任务主要是一般多视图重建或匹配，并未以智能体间的观测高度差作为主要实验变量。因此，本课题将高度、重叠度和相机几何纳入同一评测设计，检验现有能力在跨高度数据上的适用范围。对于跨高度智能体观测，仍有三个问题需要回答。

第一，高度差和视野重叠度分别会怎样影响对应关系、深度估计和点云完整率，是否存在适合不同观测高度的视图选择策略。第二，如何利用相机投影、点图、深度和匹配置信度，把高空图像的全局结构与低空图像的局部细节放入同一坐标系，并降低遮挡区域的错误融合。第三，在保持前馈推理效率的条件下，跨高度融合能否相对于同输入规模的通用前馈基线获得稳定提升。

研究这些问题可以把现有前馈式三维重建方法从一般多视图场景推进到具有明确观测层次的多智能体场景。研究结果既可为无人机与地面机器人协同采集提供视图组织依据，也可为高度变化明显、纹理不完整和局部遮挡严重的三维重建任务提供可复现实验协议。

## 二、研究目标

### 1. 总体目标

面向静态室外场景，构建一个能够处理至少两个观测高度的前馈式三维重建流程。该流程以多智能体 RGB 图像及其相机信息为输入，显式利用相对高度、投影几何、跨视角匹配和可见性置信度，将高空观测的整体结构与低空观测的局部细节融合到统一坐标系，输出具有度量尺度的深度、点图或场景点云。研究将建立高度差和视野重叠度可控的测试协议，定量分析跨高度观测相对于同高度观测的收益和代价。

### 2. 具体目标

1. **建立跨高度评测协议。** 选取包含相机参数和参考几何的公开数据，并通过视角重组或仿真形成不同高度差、视野重叠度、输入视图数量和遮挡条件的样本。所有训练、验证和测试场景按场景划分，避免相邻图像造成数据泄漏。
2. **形成有层次的基线比较。** 以 MVSNet 代表经过相机几何约束的学习式多视图深度方法，以 LoFTR 代表跨视角匹配模块，以 DUSt3R、MASt3R 和 VGGT 代表前馈式点图、匹配和多视图几何预测方法。比较时统一输入视图数量、图像分辨率、坐标变换和评价阈值，区分模型本身能力与输入条件差异。
3. **设计高度感知的几何融合方法。** 在多尺度视觉特征或点图表示中加入相对高度和观测方向信息，利用相机投影关系将不同高度的特征映射到共同参考系，再结合深度一致性、视线可见性和网络置信度进行加权融合。对于重叠不足或遮挡严重的区域，保留不确定性信息并减少低置信度点对整体模型的污染。
4. **分析高度条件下的失效机制。** 按高度差、视野重叠度、表面类型和遮挡程度统计准确率、完整率、匹配成功率和点云错误类型，分析模型在屋顶、立面、道路和弱纹理区域的表现，明确不同智能体观测对重建质量的贡献。
5. **验证精度与效率的平衡。** 在同一硬件、输入分辨率和预处理条件下，对比前馈基线与所提融合方案的质量、推理时间和显存占用，评估方法是否适合多智能体快速测绘和后续在线应用。

## 三、主要内容与技术路线

### 1. 数据构建与观测建模

研究对象限定为静态室外局部场景，主要实验使用 4 至 8 张 RGB 图像，至少包含两个观测高度。主实验假定相机内参和各视角位姿已知，以便单独研究跨高度融合对重建质量的影响。根据实验条件增加使用 DUSt3R 或 VGGT 预测相机参数的扩展实验，用于评估弱相机先验条件下的适用性。数据将记录相对高度、相机朝向、地面采样尺度、视野重叠率和参考点云误差等信息。

### 2. 基线复现与统一实现

首先复现 MVSNet 的多视图深度推断流程，检查代价体和相机投影在不同高度下的行为。然后使用 LoFTR 分析跨高度像素对应关系，并将匹配结果与三角化或深度预测结合。DUSt3R、MASt3R 和 VGGT 用于建立前馈式点图、匹配和多视图几何预测基线。每个基线都记录输入图像数量、是否使用相机先验、是否需要全局对齐以及推理资源，确保实验结论可比较。

### 3. 高度感知的前馈融合模块

模型流程包括多尺度特征提取、跨高度对应建立、共同坐标系变换、置信度估计和点云融合。特征对齐阶段利用相机投影或预测点图建立跨视角关联，并把相对高度和观测方向编码为辅助条件。融合阶段同时考虑深度残差、视线可见性、局部纹理质量和网络输出置信度。高空视图优先提供整体结构约束，低空视图用于补充立面和近地细节，重复或冲突点通过几何一致性和置信度进行筛选。模型最终输出统一坐标系下的点云，并保留深度和置信度以支持误差分析。

### 4. 对比、消融与泛化实验

实验将设置同高度观测、跨高度观测和不同视野重叠度三类条件，逐步改变高度差和输入视图数量。主要对比包括无高度信息、仅特征融合、加入投影对齐、加入可见性加权和完整模型。消融实验用于判断高度编码、点图对齐、匹配模块和置信度融合各自的贡献。测试集将覆盖训练中未出现的场景，并报告不同高度差区间的性能曲线和典型失败案例。

## 四、技术指标与预期目标

具体阈值将在预实验完成后结合数据分辨率和参考点云精度校准，最终报告中固定评测协议。

- **输入与输出**  支持至少两个观测高度和 4 至 8 张 RGB 图像。输出统一坐标系下的深度、点图或度量点云，并保存必要的置信度信息。
- **重建质量**  在与训练场景分离的测试集上报告几何准确率、完整率、F-score 和 Chamfer 距离。以相同输入条件下的最佳前馈基线为参照，目标是使完整模型的平均 F-score 提升至少 3 个百分点。点云匹配阈值暂以 0.20 米为候选值，并根据场景尺度和参考数据精度确定最终值。
- **跨高度鲁棒性**  至少覆盖三档高度差和三档视野重叠度，分别报告同高度与跨高度结果，给出屋顶、立面、道路和弱纹理区域的分项统计。重点考察完整率下降、错误匹配比例和遮挡区域重建质量。
- **推理效率**  在固定输入分辨率、单张 GPU 和统一预处理条件下，统计从图像输入到点云生成的中位耗时、峰值显存和有效点数。以 8 张图像为上限时，目标是中位推理时间不超过 5 秒，并记录硬件型号、软件环境和批处理设置。
- **可复现性**  保存数据划分、相机坐标约定、随机种子、模型配置、评价脚本和失败案例。每个实验至少重复三次或使用固定随机种子，报告均值和波动范围。

## 五、预期成果

1. 一套包含高度差、视野重叠度和遮挡条件标注的跨高度多视图重建评测协议。
2. 一套包含 MVSNet、LoFTR、DUSt3R、MASt3R 和 VGGT 对比结果的统一实验基线。
3. 一个结合相机几何、相对高度和可见性置信度的前馈式跨高度融合方法。
4. 一份包含定量指标、消融实验、效率分析和失败案例的研究报告及答辩论文。
5. 可运行的预处理、推理、评价和点云可视化代码，便于后续扩展到无人机与地面机器人协同观测。
