# 跨高度智能体观测下的前馈式三维重建

## 一、研究背景与意义

多视图三维重建已从依赖逐场景特征匹配、相机几何求解和迭代优化的传统流程，发展到由前馈式视觉几何模型直接预测相机姿态、深度图和稠密点图。一次或少量前向计算即可生成场景几何，为降低重建时延、支持在线感知提供了新的技术基础。近年来，研究开始通过稀疏跨视角注意力、关键帧缓存和模型适配减少长序列或大量视图带来的计算与显存开销，说明提升重建效率已成为前馈式方法的重要方向。[VGGT](https://arxiv.org/abs/2503.11651)、[MapAnything](https://arxiv.org/abs/2509.13414)、[SGAR](https://arxiv.org/abs/2611.26493)、[Eco3R](https://arxiv.org/abs/2611.18099)

不过，通用前馈重建模型仍需在视觉特征表达、跨视角信息交互和三维几何预测之间投入较多计算资源。模型在实验工作站上的高质量重建结果，并不自动满足无人机端对模型规模、推理时延、显存和功耗的约束。跨高度多智能体观测又要求各视角保留足够的几何细节，避免轻量化过程中丢失对齐和遮挡判断所需的信息。近期研究已经开始探索多智能体局部点图合并、跨高度或跨地理视角配准以及大范围无人机影像处理，但针对资源受限机载设备的轻量模型设计与精度—速度平衡仍值得深入研究。[MAGiSt3R](https://arxiv.org/abs/2607.15211)、[X-VGGT](https://arxiv.org/abs/2611.07575)、[GeoFF3D](https://arxiv.org/abs/2608.28288)

无人机与地面或低空平台能够提供互补视角。高位图像有利于恢复道路、屋顶和建筑群的整体结构，低位图像有利于补充立面及近地细节。高度差会引起图像尺度、视野覆盖和遮挡关系变化，因此轻量前馈模型仍需利用相机几何和跨视角信息维持重建质量。本课题将重点研究如何在有限算力下压缩前馈模型的推理开销，并保留跨高度几何对齐与多智能体融合能力，使三维重建更接近无人机在线部署需求。相对高度和视野重叠度用于构造测试工况，检验模型的鲁棒性。

## 二、主要内容（含技术指标）及目标

本课题面向静态室外局部场景，输入来自至少两个观测高度的 4 至 8 张 RGB 图像。主实验使用已知相机内参和位姿，以便在可控条件下研究模型效率与跨高度几何融合。首先选取一种公开的前馈式几何模型作为高精度教师基线，测量其重建质量、推理速度、参数量和显存占用；随后尝试构建轻量学生模型，通过特征蒸馏及深度、点图等几何监督，压缩图像编码和跨视角信息交互的计算量。模型结合相对高度与相机投影信息完成视角特征对齐，并根据几何一致性、可见性或预测置信度融合局部结果，输出统一坐标系下的度量点云。各智能体可先生成局部几何，再依据相机位姿和置信度合并到共同场景模型。

**研究目标**是构建适合无人机端运行的轻量化前馈重建方法，在显著降低模型参数量、显存占用和推理时延的同时，使重建质量接近高精度教师模型。实验以独立测试场景评估模型，并在不同高度差、视野重叠度和遮挡条件下检查精度稳定性。以下技术指标为拟定目标，最终数值将依据可用数据集、选定机载计算平台和预实验结果校准。

- **输入与输出**：支持至少两个观测高度和 4 至 8 张 RGB 图像，输出统一坐标系下具有度量尺度的稠密点云。
- **模型轻量化**：学生模型参数量及峰值显存相较教师基线降低至少 50%，记录模型文件大小和实际运行占用。
- **实时性能**：在选定的机载计算平台和固定图像分辨率下，处理 4 至 8 张图像的重建吞吐目标达到每秒 10 次，报告中位推理时延及硬件配置。
- **精度保持**：在相同输入和评价协议下，学生模型的平均 F-score 相对教师基线下降不超过 2 个百分点，并报告几何准确率、完整率及 Chamfer 距离。点云距离阈值暂以 0.20 米为候选值，需按参考几何精度校准。
- **跨高度鲁棒性**：在不同高度差、视野重叠度及遮挡条件下验证精度保持情况，统计各工况的 F-score、完整率和推理时延。
