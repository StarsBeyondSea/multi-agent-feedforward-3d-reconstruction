# 跨高度智能体观测下的前馈式三维重建

## 一、研究背景与意义

三维重建研究已从依赖局部特征匹配、相机几何求解和逐场景优化的传统多视图流程，逐步发展到利用学习式深度估计、跨视角特征关联和视觉几何基础模型，直接从多张图像预测相机与场景几何。总体趋势是增强大视角、低纹理和稀疏观测下的几何对应能力，并将深度、点图、相机姿态与尺度信息纳入统一预测，使重建能够以较少的逐场景迭代获得稠密三维结果。相关研究已形成从多视图深度推断、稠密图像匹配到前馈式点图和度量几何预测的技术基础。[MVSNet](https://arxiv.org/abs/1804.02505)、[LoFTR](https://arxiv.org/abs/2104.00680)、[DUSt3R](https://arxiv.org/abs/2312.14132)、[MASt3R](https://arxiv.org/abs/2406.09756)、[VGGT](https://arxiv.org/abs/2503.11651)、[MapAnything](https://arxiv.org/abs/2509.13414)

近期研究进一步把关注点从单个视角组的局部重建扩展到多智能体的局部几何合并、地理坐标锚定和大范围影像分块。整体上，研究目标正由提高单次重建质量，延伸到如何把不同设备、不同序列得到的几何结果稳定地变换到共同坐标系，并兼顾度量尺度、累计漂移和处理规模。多智能体前馈重建、地面与卫星影像配准以及无人机大范围重建已开始涉及这些问题。[MAGiSt3R](https://arxiv.org/abs/2607.15211)、[X-VGGT](https://arxiv.org/abs/2611.07575)、[GeoFF3D](https://arxiv.org/abs/2608.28288)

不过，从本课题重点梳理的代表性工作来看，跨高度观测通常还没有被作为统一、可控制的实验变量来系统研究。无人机或高位平台能够提供场景整体结构，低空或地面智能体能够补充立面与近地细节，但高度差也会带来地面采样尺度变化、视角差异、重叠区域减少和遮挡关系改变。若不考虑这些因素而直接融合多视图结果，可能造成对应关系错误、局部几何冲突、尺度不一致或点云缺失。因此，有必要研究如何在前馈重建框架下利用高度与相机几何信息，融合不同智能体的互补观测，并定量分析高度差和视野重叠度对重建效果的影响。该研究可为无人机与地面机器人的协同测绘、巡检和导航提供更高效的三维建模依据。

## 二、主要内容（含技术指标）及目标

本课题面向静态室外局部场景，研究至少两个观测高度下的多智能体 RGB 图像重建。主实验以相机内参和各视角位姿已知为条件，集中分析跨高度几何融合本身的作用。首先选择一种可运行的前馈式多视图重建模型作为基线，统一图像预处理、坐标变换和点云评价流程；随后围绕跨高度的尺度与可见性差异，尝试将相对高度、相机投影关系和多视图深度或点图用于特征对齐，并依据几何一致性、可见性及预测置信度融合不同视角的结果，输出统一坐标系下具有度量尺度的场景点云。实验将控制输入图像数量、高度差和视野重叠度，比较同高度与跨高度观测，并通过模块消融和失败案例分析判断融合策略的作用。

**研究目标**是建立一套跨高度前馈式三维重建和评价流程，明确不同高度观测对场景整体结构与局部细节的贡献，降低遮挡和低重叠条件下的几何错位，并验证高度感知对齐与置信度融合相较前馈基线的效果。技术指标暂定如下，具体阈值将依据数据精度和实验设备在预实验后校准。

- **输入与输出**：支持至少两个观测高度，输入 4 至 8 张 RGB 图像，输出统一坐标系下的稠密点云。
- **重建质量**：在与训练场景分离的测试集上报告几何准确率、完整率、F-score 和 Chamfer 距离。以同等输入条件下的前馈基线为参照，目标为平均 F-score 提升至少 3 个百分点。点云距离阈值暂以 0.20 米为候选值，并根据参考几何精度确定最终设置。
- **跨高度表现**：至少比较三档高度差和三档视野重叠度，分别报告同高度与跨高度的重建结果，并分析屋顶、立面、道路及遮挡区域的表现。
- **推理效率**：在固定图像分辨率和单张 GPU 条件下，测量 8 张图像输入时的中位推理时间和峰值显存。暂定中位推理时间不超过 5 秒，并记录硬件与软件配置。
