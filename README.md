# 跨高度智能体观测下的前馈式三维重建

## 一、研究背景与意义

在园区测绘、建筑巡检和机器人导航等任务中，无人机与地面机器人可以从不同高度获取同一场景的图像。高空视角能够覆盖屋顶、道路和建筑群的整体布局，低空及近地视角则能够观察建筑立面、入口和被上方结构遮挡的细节。融合这些互补观测，有望在有限采集次数下提高三维模型的覆盖范围和几何完整性。然而，高度差通常伴随明显的视角变化、成像尺度差异和可见区域变化。跨高度图像的共同可见区域较小时，局部特征更难建立可靠对应，容易造成重建缺失或几何错位。

传统多视图重建通常需要针对每个场景执行特征匹配、几何求解和迭代优化。前馈式重建利用预先训练的模型，在推理阶段通过一次前向计算预测场景几何，为缩短重建时间提供了可行途径。本课题拟研究不同高度的图像如何在统一坐标系中进行几何对齐与特征融合，并通过实验分析高度差和视野重叠度对重建质量的影响，为多智能体协同测绘提供方法和评价依据。

## 二、主要内容、技术指标及目标

本课题以静态室外场景为研究对象，设定相机内参与各视角位姿已知。模型接收来自至少两个观测高度的多视图 RGB 图像，输出统一坐标系下的场景点云。研究首先选取具备相机参数和参考几何的公开数据，并利用仿真补充可控制高度差和视野重叠度的样本。随后复现一种前馈式多视图重建方法作为基线，在此基础上利用相机投影关系对齐多尺度图像特征，并根据各视角的可见性或深度预测置信度加权融合，减少遮挡区域的错误匹配对重建的影响。实验将分别控制输入视图数量、高度差和视野重叠度，对比同高度与跨高度观测的重建结果，并通过消融实验检验各模块的作用。

拟定技术指标如下，具体阈值在预实验后确定。

- **输入与输出**：支持至少两个观测高度、共 4 至 8 张 RGB 图像，单次前向推理生成具有统一坐标和度量尺度的场景点云。
- **重建质量**：在与训练场景分离的测试集上，以参考点云为依据，报告几何准确率、完整率和 F-score。在相同输入和评估条件下，拟定目标为较前馈基线的平均 F-score 提升 3 个百分点。室外局部场景可暂以 0.20 米作为点云匹配阈值，并依据参考数据的精度和场景尺度在预实验阶段确定最终取值。
- **推理效率**：在固定输入分辨率和单张 GPU 的条件下，报告从已预处理的 8 张图像输入到点云生成的中位耗时和峰值显存。拟定目标为中位耗时不超过 5 秒，实验时记录硬件型号和输入分辨率。
