# 参考文献

本目录收录与跨高度多智能体观测、学习式多视图立体重建、跨视角匹配和前馈式三维几何预测相关的开放获取论文。PDF 来源均为 arXiv。

1. Yao, Y., Luo, Z., Li, S., Fang, T., and Quan, L. **MVSNet: Depth Inference for Unstructured Multi-view Stereo.** ECCV 2018. arXiv:1804.02505. 经典学习式多视图立体重建基线，可参考其深度推断与视图聚合设计。 [论文页面](https://arxiv.org/abs/1804.02505)
2. Sun, J., Shen, Z., Wang, Y., Bao, H., and Zhou, X. **LoFTR: Detector-Free Local Feature Matching with Transformers.** CVPR 2021. arXiv:2104.00680. 讨论无需关键点检测器的跨图像特征匹配，可作为跨高度视角对应关系研究的参考。 [论文页面](https://arxiv.org/abs/2104.00680)
3. Wang, S., Leroy, V., Cabon, Y., Chidlovskii, B., and Revaud, J. **DUSt3R: Geometric 3D Vision Made Easy.** CVPR 2024. arXiv:2312.14132. 通过前馈网络从图像对预测点图，为无需传统逐场景优化的几何重建提供了代表性方案。 [论文页面](https://arxiv.org/abs/2312.14132)
4. Leroy, V., Cabon, Y., and Revaud, J. **Grounding Image Matching in 3D with MASt3R.** ECCV 2024. arXiv:2406.09756. 将图像特征匹配与三维几何联系起来，适合参考跨视角特征对应及几何约束设计。 [论文页面](https://arxiv.org/abs/2406.09756)
5. Wang, J., Chen, M., Karaev, N., Vedaldi, A., Rupprecht, C., and Novotny, D. **VGGT: Visual Geometry Grounded Transformer.** CVPR 2025. arXiv:2503.11651. 研究以一次前向推理联合预测多视图几何，可作为本课题前馈式重建方向的重要近年参考。 [论文页面](https://arxiv.org/abs/2503.11651)

文件名中的 arXiv 编号可用于检索论文版本及 BibTeX 信息。引用前请核对所采用版本的作者、会议版本和格式要求。
